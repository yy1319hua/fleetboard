## 1. Visual Theme & Atmosphere（视觉主题与氛围）

**一句话**：一台"夜间运维控制台"——冷静、密集、状态一眼可辨，不炫技。

- **深色优先**：运维多在夜间/长时间盯屏，默认深色；提供浅色主题但以深色为设计基准。
- **数据密度优先**：列表行高 40px、正文 14px，比通用 SaaS 更密，接近 IDE/终端。
- **克制装饰**：无渐变、无玻璃拟态、无发光边框；层次靠**表面色差 + 1px 边框**，不靠投影。
- **状态即语言**：在线/离线/警告/错误用固定语义色 + 圆点 + 文本，不依赖颜色单通道（色盲可用）。
- **控制台节奏**：分组标题与表头用**小号大写 + 0.06em 字距**，形成"提示符"韵律（借鉴 Sentry，但不用其紫+青柠）。

## 2. Color Palette & Roles（色板与语义角色）

> 深色为基准；所有中性色**带冷蓝调**，不用纯黑/纯白（impeccable 反模式）。

### 表面（Surface）
| Token | Hex | 用途 |
|---|---|---|
| `--bg` | `#0f1115` | 页面底（带蓝调近黑，非 #000） |
| `--surface-1` | `#161a21` | 卡片/面板 |
| `--surface-2` | `#1d222b` | 悬浮层/表头/输入底 |
| `--surface-3` | `#242a35` | 选中行/按压态 |
| `--border` | `#2a303b` | 1px 分隔线/卡片边框 |
| `--border-strong` | `#3a4250` | 聚焦/强调边框 |

### 文字（Text）
| Token | 值 | 用途 |
|---|---|---|
| `--text` | `#e6e9ef` | 主文字（暖白，非纯白） |
| `--text-muted` | `#9aa4b2` | 次级说明 |
| `--text-faint` | `#6b7480` | 占位/禁用 |
| `--text-inverse` | `#0f1115` | 亮色填充上的文字 |

### 主强调（Accent，唯一暖色）
| Token | Hex | 用途 |
|---|---|---|
| `--accent` | `#e8a33d` | 主按钮、选中项、焦点环、当前导航 |
| `--accent-hover` | `#f0b45a` | 悬停 |
| `--accent-soft` | `rgba(232,163,61,0.14)` | 选中背景/高亮底 |

> 为什么是琥珀：冷色背景里唯一暖色，辨识度高，且**不与语义状态色抢位**。全站强调色只此一个（impeccable：强调色要稀缺）。

### 语义状态（Semantic，固定不可挪用）
| Token | Hex | 含义 |
|---|---|---|
| `--ok` | `#3fb950` | 在线 / 成功 / 运行中 |
| `--warn` | `#d29922` | 警告 / 阈值接近 |
| `--danger` | `#f85149` | 错误 / 离线 / 删除 |
| `--info` | `#58a6ff` | 信息 / 进行中 |
| `--idle` | `#8b949e` | 未知 / 已停止 |

> 语义色**只用于状态**，绝不作装饰或按钮主色（impeccable：不要为强调色扩列）。

### 浅色主题（可选，M6 后期）
`--bg #f7f8fa` / `--surface #ffffff` / `--text #1a1f26` / `--border #e3e6eb`，语义色不变（对比度校验后微调）。

## 3. Typography Rules（字体规则）

**明确不用 Inter / Arial / 系统默认**（impeccable 头号反模式）。

| 角色 | 字体 | 回退 |
|---|---|---|
| UI 正文/标题 | **Geist Sans** | `-apple-system, "Segoe UI", "Noto Sans SC", sans-serif` |
| 等宽（日志/路径/ID/代码） | **JetBrains Mono** | `Menlo, Consolas, monospace` |
| 中文 | 系统中文（`Noto Sans SC` / `PingFang SC`） | — |

### 字号层级（密度优先）
| Token | 字号/行高/字重 | 用途 |
|---|---|---|
| `display` | 30/1.2/600 | 页面主标题 |
| `h1` | 22/1.3/600 | 区块标题 |
| `h2` | 18/1.35/600 | 卡片标题 |
| `h3` | 15/1.4/600 | 小节标题 |
| `body` | 14/1.5/400 | 默认正文/表格 |
| `body-sm` | 13/1.5/400 | 辅助说明 |
| `caption` | 12/1.4/500 | 标签/时间戳 |
| `eyebrow` | 11/1.4/600 + `0.06em` 大写 | 分组标题/表头 |
| `mono` | 13/1.6/400 | 日志/路径/ID |
| `mono-sm` | 12/1.6/400 | 紧凑日志 |

> 行高两档：正文 1.5（密集 UI），日志 1.6（可读）。数字统一 `font-variant-numeric: tabular-nums`（表格/监控对齐）。

## 4. Component Stylings（组件样式）

### 按钮
| 变体 | 背景 | 文字 | 边框 | 圆角 | 内边距 |
|---|---|---|---|---|---|
| primary | `--accent` | `--text-inverse` | 无 | 6px | 8×14 |
| secondary | `--surface-2` | `--text` | 1px `--border` | 6px | 8×14 |
| ghost | 透明 | `--text-muted` | 无 | 6px | 8×10 |
| danger | `--danger` | `#fff` | 无 | 6px | 8×14 |

- 高度：默认 34px，移动端 ≥44px；禁用态降到 40% 不透明。
- 焦点：`outline: 2px solid --accent; outline-offset: 2px`（键盘可见）。

### 卡片/面板
- 背景 `--surface-1`，1px `--border`，圆角 8px，内边距 16/20px。
- **不嵌套卡片**（impeccable）：卡内分组用 `--border` 分隔线或 `--surface-2` 区块，不再套第二层卡。
- **不加投影**：深色面投影会脏，层次靠色差 + 边框。

### 表格（容器/文件/服务器列表）
- 行高 40px，表头 `eyebrow` + `--surface-2`，行间 1px `--border`，无斑马纹。
- 悬停行 `--surface-3`；选中行左侧 2px `--accent` 竖条。
- 等宽列（IP/端口/大小/时间）用 `mono` + tabular-nums。

### 状态徽标
```
● 在线     --ok
● 离线     --danger（或 --idle 表示未知）
● 警告     --warn
```
- 圆点 8px + 12px 文字；**同时给文字**，不只靠颜色。

### 日志终端
- 底 `#0b0d10`，`mono` 13/1.6，自动滚动可暂停，虚拟滚动（万行不卡）。
- 级别着色：ERROR `--danger`、WARN `--warn`、INFO `--info`，其余 `--text`。

### 输入/表单
- 输入：`--surface-2` 底、1px `--border`、圆角 6px、高 34px、内边距 8×10。
- 聚焦：边框 `--accent` + 2px 焦点环。
- 开关/复选：选中 `--accent`。

### 导航
- **桌面**：左侧 216px 固定栏，当前项 `--accent-soft` 底 + `--accent` 左侧 2px 竖条。
- **移动（PWA）**：底部 Tab（总览/容器/文件/监控/设置），全功能，不隐藏编辑入口（用户已定 mobile 全功能）。

## 5. Layout Principles（布局原则）

- **间距基准 4px**：4 / 8 / 12 / 16 / 24 / 32 / 48。
- **圆角**：4（徽标）/ 6（按钮输入）/ 8（卡片）/ 12（大容器）/ 999（药丸）。
- **栅格**：内容最大宽 1440px（运维面板偏宽），桌面 12 列，间距 16px。
- **密度哲学**：列表/表格密集（40px 行），概览页呼吸（卡片间距 16、区块 32）。

## 6. Depth & Elevation（层级）

| 级 | 处理 | 用途 |
|---|---|---|
| 0 | 无 | 默认表面 |
| 1 | 1px `--border` | 卡片/面板 |
| 2 | `--surface-2` + 边框 | 弹出/下拉/悬浮层 |
| 3 | `0 8px 24px rgba(0,0,0,.4)` | 模态/命令面板（唯一允许投影处） |

> 深色主题下**不用阴影做卡片层次**（会脏），只用边框与表面色差。

## 7. Do's and Don'ts（护栏，源自 impeccable）

### ✅ Do
- 强调色只用一个（琥珀），且只用于主操作/选中/焦点。
- 状态色只表达状态，红只给错误/删除/离线。
- 数字用等宽 + tabular-nums，表格/监控对齐。
- 交互目标移动端 ≥44×44px。
- 文本对比度 ≥ 4.5:1（用工具校验）。
- 动效 120–200ms、`ease-out`，只做透明度/位移。

### ❌ Don't
- ❌ 不用 Inter / Arial / 系统默认字体。
- ❌ 不用纯黑 `#000` / 纯白 `#fff`（一律带色调）。
- ❌ 不用紫蓝渐变、发光边框、玻璃拟态。
- ❌ 不在彩色背景上放灰色文字。
- ❌ 不卡片套卡片。
- ❌ 不用弹跳/弹性缓动（`cubic-bezier` 回弹）、不用无限旋转装饰。
- ❌ 不用颜色作为唯一状态信号（必须配文字/图标）。
- ❌ 不引入第二个强调色（青绿/橙/黄都不加）。

## 8. Responsive Behavior（响应式）

| 断点 | 变化 |
|---|---|
| ≥1280 | 左栏 216px + 内容区，表格全列 |
| 1024–1279 | 左栏 200px，表格隐藏次要列 |
| 768–1023 | 左栏收为图标栏 64px 或抽屉 |
| <768 | 底部 Tab 导航，单列，卡片全宽，表格转卡片列表 |
| 触控 | 点击目标 ≥44px；日志/表格横向滚动不挤压 |
